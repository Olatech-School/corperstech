# CorpersTech v1.0 — Version 1 Release Notes

We are thrilled to officially announce the **Gold Release (v1.0.0)** of CorpersTech! 

CorpersTech is a specialized digital admissions ecosystem designed specifically for Nigerian NYSC corps members transitioning into technology careers through the **Olatech School of Programming**.

---

## New Features & Enhancements

### 🚀 Student Lifecycle Funnel
- **Home Portal**: Clean, high-contrast, fully responsive hero components focused on skill transition.
- **Course Navigator**: Dynamic breakdowns of key courses (Cybersecurity, Data Analysis, Software Engineering) highlighting duration, tools taught, and syllabus.
- **Application Flow**: Fluid multi-step wizard supporting custom transport choices and coordinate matching.
- **Tracking Core**: Real-time reference tracker (`CT-2026-XXXX`) allowing instant applicant status verification.

### 💼 Career Launch Hub
- **Optimization Matrix**: Guided steps for student portfolios, GitHub deployments, and CV ATS formatting.
- **Technical Mentorship**: Interactive mock panel prep tools and download hubs for resource booklets.

### 📊 Administrative CRM (Admissions Command Center)
- **CRM Metrics Dashboard**: Instantly track pending lists, approved candidates, bus registrations, and registration trends.
- **Cohort Allocator**: Create learning cohorts and map candidates to specific trainers.
- **Transport Manifest Desk**: Print real-time passenger sheets and coordinate drivers.
- **Orientation Matrix Checklists**: Tracking tools for doc submissions, laptop readiness, and payment confirmations.
- **Spreadsheet Integration**: Export real-time spreadsheets via the **Export CSV** button.

---

## Architectural & Security Foundation

- **Robust Framework**: Powered by React, Vite, Tailwind CSS, Express.js, Prisma ORM, and MySQL.
- **Total Security Isolation**: Sensitive environment credentials remain strictly server-side.
- **Database Safety**: Implement soft-delete patterns to protect applicant records from accidental deletion.
- **Accessibility AA Standard**: High-contrast typography scale featuring Poppins, Inter, and JetBrains Mono.
